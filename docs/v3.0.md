## What’s new in v3.0

### 1) Mount control (preMounted / keepMounted)

You can control the mounting strategy per presenter.

- **preMounted**: the presenter component may be mounted **before** it becomes active (it can be hidden until opened).
- **keepMounted**: once mounted, closing only hides it; re-open does not re-mount.

Defaults are both `false`.

You can configure global defaults via `createLayergeRouter({ presenterDefaults })` and override per call.

#### mountPreset

A convenience preset that expands to (`preMounted`, `keepMounted`):

| preset | preMounted | keepMounted |
|---|---:|---:|
| `default` | false | false |
| `keep` | false | true |
| `pre` | true | false |
| `prekeep` | true | true |

Priority:
1. PresenterOptions (call site)
2. `presenterDefaults`
3. fallback (both false)

---

### 2) url option (successor of fakePath)

`fakePath` is deprecated in favor of `url`.

- Type: `string | RouteLocationRaw`
- Applies to: **push / replace only**
- `open()` ignores `url` (dev warn)

#### RouteLocationRaw merge

When `url` is a partial location (e.g. only `query`/`hash`), Layerge merges it with the current route, then resolves.

#### router-link behavior: no-op on same fullPath

If the resolved `url` becomes the same `fullPath` as the current route, Layerge will **no-op** to prevent history bloat.

---

### 3) controlledHooks (opt-in, global)

v2 notification hooks remain supported.

v3 adds **controlledHooks** (opt-in) which can cancel operations:

- `beforeOpen`
- `beforeClose`
- `beforeNavigate`

Return contract:

- `false` => cancel
- `true | void` => continue
- `Promise` => awaited
- throw => cancel (safe default)

`ctx.signal` (AbortSignal) is provided for latest-wins cancellation; results from superseded attempts must not be applied.

> Ordering: Local guards (Presenter scope) are evaluated first, then global controlledHooks.

---

### 4) Local leave guard (Composable)

A presenter can register one or more leave guards.
Guards are evaluated with AND logic (any `false` cancels).

Recommended shape:

```ts
usePresenterLeaveGuard({
  when: dirty,               // boolean | Ref<boolean> | () => boolean
  confirm: () => Promise<boolean>,
  guardSpaNavigation: true,  // default true
})
```

---

### 5) LayergeLink unified

v3 provides a **single** `<LayergeLink>`.

- **Route mode**: `to` (RouteLocationRaw)
- **Component mode**: `component` (Vue component)

Rules:
- `to` and `component` are **mutually exclusive** (dev warn if violated)
- `url` is used only for `push/replace` (dev warn if used with `open`)

Props (minimum):

- `to?: RouteLocationRaw`
- `component?: Component`
- `url?: string | RouteLocationRaw`
- `action?: 'push' | 'replace' | 'open'` (default: `'push'`)
- `presenter?: string`
- `custom?: boolean`
- `prevent?: boolean`
- `disabled?: boolean`

---

## Compatibility notes

### Forward restore (push-only) must remain intact

v2.x introduced history.state merging under `history.state.layerge` to restore a pushed presenter via Back/Forward.

v3 changes must **not**:
- overwrite history.state destructively
- change the `layerge` namespace keys without a compatibility layer
- break the restore conditions (`mode === 'presenter'`, `entryId`, `toFullPath` match, empty stack, current page mode)
